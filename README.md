# 2way 차량 추적

동두천시 보건소의 전처리된 3배속 영상 8개를 분석해 차량의 **유입·유출 수량을 15분 단위로 집계**하는 로컬 프로그램입니다.

## 가장 먼저 할 일

1. `실행.bat`을 더블클릭합니다.
2. `1. 영역·통과선 설정`을 누릅니다.
3. 영상 창에서 차량이 이동하는 출입구 영역을 왼쪽 클릭으로 3점 이상 지정합니다.
4. `Enter`를 누르고 차량이 통과하는 선의 양 끝을 두 번 클릭합니다.
5. 다시 `Enter`를 눌러 저장합니다.
6. `2. 5분 시험 분석`을 실행합니다.
7. `test_results`의 검수 영상과 CSV를 사람이 센 값과 비교합니다.
8. 방향이 반대라면 `유입/유출 방향 바꾸기`를 누릅니다.
9. 결과가 맞으면 `3. 전체 24시간 분석`을 실행합니다.

영역 설정 창에서 `R`은 현재 점 초기화, `Esc`는 취소입니다.

## 판정 기준

- 화면의 오른쪽에서 왼쪽으로 선을 통과하면 기본적으로 `유입`입니다.
- 화면의 왼쪽에서 오른쪽으로 통과하면 기본적으로 `유출`입니다.
- 방향이 반대면 프로그램의 `유입/유출 방향 바꾸기`를 한 번 누르면 됩니다.
- 차량 박스의 하단 중앙점이 가상선을 완전히 통과한 경우만 셉니다.
- 동일한 추적 ID는 영상 하나에서 한 번만 집계됩니다.

## 결과 파일

결과는 기본적으로 `results` 폴더에 저장됩니다.

- `15분_유입유출_집계.csv`: 00:00부터 24:00까지 96개 구간의 유입·유출·합계
- `차량별_통과기록.csv`: 실제 시간, 방향, 차량, 추적 ID, 신뢰도, 원본 영상
- 각 영상이 끝날 때마다 `{영상명}_15분_유입유출_집계.csv`와 `{영상명}_차량별_통과기록.csv`가 별도로 저장되며, 위 전체 CSV도 즉시 갱신됩니다.
- `실행.bat` 화면에서 `출입 시각·차종 상세 CSV 저장`을 해제하면 수량 집계 CSV만 저장합니다. 체크하면 차량별 통과 시각, 유입·유출 방향, 차종을 함께 기록합니다.
- `event_images`: 차량이 통과한 순간의 확인 이미지
- `검수_*.mp4`: 검수 영상 저장을 선택했을 때 생성되는 표시 영상

검수 영상은 저장 공간을 줄이기 위해 640px·약 10fps로 생성됩니다. 실제 집계는 원본 해상도와 전체 프레임으로 수행됩니다.

시험 분석 결과는 `test_results` 폴더에 따로 저장됩니다.

## 영상 시간 환산

입력 영상은 3배속이므로 영상 5분이 실제 15분입니다. 파일명의 시작 시간과 영상 재생 시간을 이용해 실제 시간대를 자동 계산합니다.

## 성능 설정

- 기본 모델: `yolo26l.pt`
- 기본 추적기: 가림 복원용 BoT-SORT + ReID (`botsort_reid.yaml`)
- 기본 분석 크기: 960px
- ROI 실제 크롭: 활성화, 주변 여백 64px (`roi_crop_enabled`, `roi_crop_padding_px`)
- 영상 디코딩 선행 버퍼: 8프레임 (`frame_prefetch_buffer`)
- 빠른 차량: 통과선 수직 속도 15px/프레임 이상이면 통과 후 2프레임 확인
- GPU: `0`을 선택하면 NVIDIA GPU, `cpu`를 선택하면 CPU
- GPU 초기화에 실패하면 자동으로 CPU로 전환합니다.

차량이 서로 가려져 추적 ID가 바뀌는 경우를 줄이기 위해 잃어버린 트랙을 90프레임 동안 유지하고 외형 기반 ReID로 다시 연결합니다. 그래도 ID가 바뀌면 카운터가 차종과 무관하게 이동 방향, 통과선 거리와 예상 위치를 비교해 통과선 근처의 ID 조각을 한 번 더 연결합니다. 연결이 발생하면 진행 로그에 `가림 ID 연결: 이전ID → 새ID`가 표시됩니다.

통과선은 카메라 앞에 있으므로 작은 노이즈 박스는 집계에서 제외합니다. 기본 최소 조건은 오토바이를 기준으로 폭 35px, 높이 35px, 면적 2,000px²이며 `config.json`의 `min_box_width_px`, `min_box_height_px`, `min_box_area_px`에서 조정할 수 있습니다.

전체 분석 중에는 노트북 전원을 연결하고 Windows 절전 모드를 꺼 두는 것이 좋습니다. 발열이 심하면 노트북 받침대나 성능 모드를 사용하세요.

## Colab에서 사용하려면

핵심 분석 코드는 `two_way_counter.py`에 있어 Colab에서도 재사용할 수 있습니다. 다만 입력 영상 전체가 약 50GB이므로, 전체 분석은 로컬 RTX 3060에서 실행하는 편이 안정적입니다. Colab은 짧은 샘플 검증이나 모델 학습에 적합합니다.

## 설치 오류가 날 때

`설치.bat`을 한 번 실행한 뒤 다시 `실행.bat`을 실행하세요.

## 랩실 데스크톱에서 실행

GitHub 저장소를 내려받거나 ZIP으로 받은 뒤 `설치.bat`을 먼저 실행합니다. 이후 `실행.bat`을 열고 `영상 폴더`에서 전처리 영상 8개가 있는 위치를 선택하세요. YOLO 모델 파일은 첫 시험 분석 때 자동으로 내려받습니다.
